# Regix Studio

Página de desarrollador de Sergi Olivares (https://rehgix.github.io/), con la lista de sus apps.

- FullGrader tiene su propia web: https://fullgrader.app/ (repositorio `fullgrader-docs`).
- No borrar la etiqueta `google-site-verification` de `index.html`: la usa Google Search Console.
- Apps: FullGrader (fullgrader.app) e IPO Emprèn (ipo-empren.web.app).
- Colores: verde azulado (#0f766e) con acento naranja (#c2410c), definidos en `:root`.
- Para añadir una app: copiar el bloque `<article class="card live">` de `index.html`, poner su icono en `apps/` y añadir sus textos en los tres idiomas (es, ca, en) del script del final.
